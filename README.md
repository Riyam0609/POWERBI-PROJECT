UPI Transaction Analytics Dashboard – Project Report

## Problem Statement

Digital payment platforms generate massive transactional data every day. The challenge is to convert this raw UPI transaction data into meaningful insights that help understand platform performance, user behavior, usage patterns, and retention. The objective of this project is to design an interactive Power BI dashboard to analyze UPI transaction patterns, user behavior, and revenue performance.


## Dataset Overview

The dataset contains UPI transaction records with key fields such as Transaction ID, Transaction Type, Transaction Value, Revenue, City, User Age, User Gender, Device Used, User Type, User Retention, Time of Day, and Day of the Week. This data represents user transactions across multiple cities, devices, and time periods.

Data Preprocessing Steps

1.	Corrected data types for numeric and categorical fields.
2. Removed blank and null values.
3. Ensured proper aggregation (Sum/Count) for KPI visuals.
4. Verified consistency in categorical columns like City, Device, Gender, etc.
5. Applied sorting for tables and charts.
6. Added slicers for interactive filtering.
2.	
Sheets / Pages Created in the Report
Page 1 – UPI Performance Overview:
KPI Cards for total transactions, transaction value, and revenue; donut chart for transaction types; bar chart for city performance; slicers for City, Transaction Type, and User Type.

Page 2 – User Insights:
Treemap for gender contribution; stacked column chart for device vs gender; ribbon chart for age vs transaction type; funnel chart for user type; slicers for Device and City.

Page 3 – Usage Pattern & Retention:
Area chart for time of day; stacked bar for day vs retention revenue; donut chart for retention share; table for detailed transactions; slicers for Day of Week and User Retention.


## Key Insights and Findings

• Certain cities contribute higher transaction value.
• UPI usage peaks during specific times of the day and certain days.
• Mobile devices dominate transaction activity.
• Returning users contribute more to overall revenue.
• Specific age and gender groups show higher engagement.
• Retained users generate more consistent revenue than churned users.


Final Assumptions and Business Recommendations

Assumptions:
• Data reflects realistic user behavior.
• Revenue correlates with transaction value.
• Retention indicates engagement.

Recommendations:
• Focus marketing on high-performing cities.
• Offer incentives during low-usage periods.
• Optimize app experience for commonly used devices.
• Introduce loyalty programs for new users.
• Target key age groups with personalized offers.


## Final Conclusion

This project demonstrates how UPI transactional data can be transformed into actionable insights using Power BI. The dashboards provide a comprehensive view of platform perfo
rmance, user behavior, and retention patterns, enabling data-driven decision making.
